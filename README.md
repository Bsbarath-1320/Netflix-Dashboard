# 🎬 Netflix Data Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing Netflix data using Power BI
and Python.

The dashboard provides insights into customers, countries,
titles, genres, ratings, watch time, age groups, and
subscription types.

---

## 🎯 Objectives

- Analyze total Netflix customers
- Analyze total titles available
- Understand watch time
- Analyze movie and TV show performance
- Identify popular genres
- Analyze ratings by country
- Compare subscription types
- Analyze watch time by age group
- Understand subscription trends by year

---

## 🛠️ Tools & Technologies

- Power BI
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

---

## 📊 Key Performance Indicators

- Total Customers: 20K
- Total Countries: 190
- Total Titles: 20K
- Total Watch Time: 50,112,681 minutes

---

## 📈 Dashboard Modules

### 1. Genre Analysis

This module analyzes Netflix content based on different
genres.

Genres include:

- Action
- Animation
- Comedy
- Documentary
- Drama
- Fantasy
- Horror
- Romance
- Sci-Fi
- Thriller

---

### 2. Watch Time Analysis

This module analyzes total watch time based on:

- Movie
- TV Show
- Age Group
- Subscription Type

The dashboard shows approximately 25M watch minutes for
Movies and 25M for TV Shows.

---

### 3. Rating Analysis

This module analyzes ratings based on:

- Country
- Month
- Genre
- Content Type

The dashboard also compares ratings between Movies and
TV Shows.

---

### 4. Subscription Type Analysis

Subscription types analyzed:

- Basic
- Standard
- Premium

Watch time by subscription type:

- Standard: 17.3M
- Basic: 16.6M
- Premium: 16.3M

---

### 5. Age Group Analysis

Watch time is analyzed across different age groups:

- 13–18
- 19–30
- 31–45
- 46–60
- 60+

The 60+ age group has the highest share of watch time
at approximately 29.36%.

---

## 🔍 Key Insights

- Netflix data covers 190 countries.
- Total titles analyzed are approximately 20K.
- Total watch time is over 50M minutes.
- Movie and TV Show watch time are almost equally distributed.
- Standard subscription has the highest watch time.
- The 60+ age group contributes the highest watch time share.
- Ratings are analyzed across countries and months.
- Genre-level analysis helps understand content preferences.
